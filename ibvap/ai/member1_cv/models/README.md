# models/

Place custom YOLO weight files (`.pt`) here.

**Default model**: `yolov8n.pt` is auto-downloaded by Ultralytics on first run
and cached in `~/.cache/ultralytics/`.  You do not need to put anything here
for Phase 1A.

To use a model stored here:

```bash
python main.py --model models/yolov8n.pt
```
